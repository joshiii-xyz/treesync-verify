# Contributing

Keep changes within the read-only local tree comparison scope in
`docs/product-brief.md`. Do not add synchronization, backup, extraction,
frontend, hosted services, or untested compatibility claims.

Run the commands in `docs/release.md` for release changes. Review the diff and
exact validation output before committing. Never place credentials, private
paths, or secret values in source, fixtures, logs, or QA evidence.
